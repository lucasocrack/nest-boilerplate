NestJS Prisma Boilerplate

Este é um projeto boilerplate para iniciar aplicações com NestJS e Prisma. Ele vem com uma série de funcionalidades pré-configuradas para acelerar o seu desenvolvimento.

Criado e mantido por lucascampos42.

Funcionalidades

  • Framework: NestJS - Um framework Node.js progressivo para construir aplicações server-side eficientes e escaláveis.
  • ORM: Prisma - ORM de próxima geração para Node.js e TypeScript.
  • Autenticação: Autenticação completa com JWT (login e registro).
  • Autorização: Controle de acesso baseado em papéis (Role-Based Access Control - RBAC) com guards.
  • Logs de Ações do Usuário: Middleware para registrar automaticamente as ações dos usuários em uma tabela de log no banco de dados.
  • Docker: Configuração completa com Dockerfile e docker-compose.yml para um ambiente de desenvolvimento e produção containerizado.
  • Testes: Estrutura de testes com Jest para testes unitários e e2e.
  • Validação: Validação de DTOs com class-validator.
  • Cliente de API: Coleção do Bruno para testar a API.

Como Começar

Pré-requisitos

  • Node.js (v20 ou superior)
  • Docker (opcional, para rodar com Docker)
  • NPM

Instalação

  1. Clone o repositório:Example :
    git clone <URL_DO_REPOSITORIO>
  2. Instale as dependências:Example :
    npm install

Configuração do Banco de Dados

  1. Copie o arquivo .env.example para .env:Example :
    cp .env.example .env
  2. Adicione a sua URL de conexão do PostgreSQL no arquivo .env:Example :
    DATABASE_URL="postgresql://USER:PASSWORD@HOST:PORT/DATABASE?schema=public"
  3. Rode as migrações do Prisma para criar as tabelas no banco de dados:Example :
    npx prisma migrate dev

Populando o Banco de Dados (Seeding)

Este projeto inclui um script de seed para popular o banco de dados com dados iniciais. Atualmente, ele cria um usuário administrador padrão.

Para rodar o script de seed, execute o seguinte comando:

Example :
npm run seed

O usuário administrador será criado com as seguintes credenciais:

  • E-mail: admin@admin.com
  • Senha: 12345678

Rodando a Aplicação

Com NPM

Example :
# Modo de desenvolvimento
$ npm run start:dev

Com Docker

  1. Construa a imagem Docker:Example :
    docker-compose build
  2. Inicie os containers:Example :
    docker-compose up

A aplicação estará disponível em http://localhost:3099.

Rodando os Testes

Example :
# Testes unitários
$ npm run test

# Testes end-to-end (e2e)
# Certifique-se de ter um banco de dados de teste rodando
$ npm run test:e2e
